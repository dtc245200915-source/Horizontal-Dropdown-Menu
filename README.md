# Thực hành tạo Menu Dropdown Ngang

Bài thực hành tạo menu ngang hai cấp bằng HTML và CSS.

## Chức năng
- Menu chính hiển thị theo hàng ngang.
- Menu con được ẩn mặc định bằng `visibility: hidden`.
- Khi rê chuột vào **Sản phẩm** hoặc **Dịch vụ**, menu con xuất hiện.
- Khi rê chuột qua liên kết, nền chuyển sang màu đỏ.
- Menu con được đặt bên dưới menu cha bằng `position: absolute` và `top: 40px`.

## Chạy bài
Mở `index.html` bằng trình duyệt hoặc Live Server.
